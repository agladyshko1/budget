# Мій бюджет — офлайн-застосунок

Працює без інтернету. Усі записи зберігаються на телефоні.

## Що в архіві
- `index.html` — сам застосунок
- `manifest.webmanifest` — назва та іконка для встановлення
- `sw.js` — відповідає за роботу офлайн і оновлення
- `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` — іконки

## Встановлення (один раз, ~15 хв, зручніше з комп'ютера)

1. **Збережи дані зі старого трекера.** Відкрий його в Claude → «План на місяць» → «Завантажити всі записи (CSV для Excel)».
2. **Зареєструйся на github.com** (безкоштовно).
3. Натисни **New repository** → назва `budget` → **Public** → **Create repository**.
4. На сторінці репозиторію: **uploading an existing file** → вибери всі 7 файлів (можна прямо з телефона) → **Commit changes**.
5. **Settings → Pages** → у «Source» вибери **Deploy from a branch** → гілка **main**, папка **/(root)** → **Save**.
6. Через 1–2 хвилини застосунок буде за адресою `https://ТВІЙ-ЛОГІН.github.io/budget/`.
7. **На телефоні** відкрий цю адресу в Chrome → меню ⋮ → **«Встановити застосунок»** (Install app).
8. Відкрий застосунок → «Резервні копії та імпорт» → **«Імпортувати записи з CSV»** → вибери файл з кроку 1.
9. Перевір офлайн: увімкни режим польоту й відкрий застосунок.

## Оновлення
1. Заміни змінені файли в репозиторії на GitHub.
2. У `sw.js` збільш `VERSION` (наприклад, `1.0` → `1.1`), у `index.html` — `APP_VERSION`.
3. Наступного разу з інтернетом застосунок покаже «Є нова версія» → **Оновити**. Записи збережуться.

## Безпека даних
- Записи живуть лише на цьому телефоні. Раз на тиждень роби копію (застосунок нагадає).
- Не очищай дані сайту `github.io` у Chrome і не видаляй застосунок без свіжої копії.
- Для синхронізації з хмарою в майбутньому все готово: кожен запис має унікальний ID і час зміни, видалення теж фіксуються.
